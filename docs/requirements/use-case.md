# Use Cases

## 1. Overview

本書は BR・FR に基づき、ドライバー（および運送会社）が Safar をどう使うかを整理する。主要な業務フロー・アクター・ゴールをまとめる。

---

## 2. Use Case List

| UC ID | Related BR ID | Related FR ID | Title | Actor | Goal |
|---|---|---|---|---|---|
| UC-002 | BR-002, BR-005 | FR-006, FR-007, FR-008, FR-009 | コンビニ商品のハラル可否を判定する | ドライバー | 棚の前で商品をスキャンし、食べてOKか即時に判断する |
| UC-003 | BR-002 | FR-010, FR-011 | 食べられるものを事前に把握する | ドライバー | コンビニ別/ルート上で食べられる選択肢を事前に知る |
| UC-004 | BR-003, BR-006 | FR-013, FR-012 | 伝票・指示を翻訳して現場対応する | ドライバー | 伝票や倉庫指示を撮影/参照し、自分の言語で理解して対応する |
| UC-005 | BR-003, BR-006 | FR-012, FR-014 | 点呼・事故対応のフレーズを使う | ドライバー | 点呼や事故・トラブル時の定型日本語を音声で使う |

---

## 3. Notes

- `UC ID` は `UC-001` 形式で採番する。
- `Related BR ID` / `Related FR ID` で事業要件・機能要件を参照する。
- 画面・データ・外部連携の詳細は `specifications/` で管理する。
- UC-007 は P2。
- 道（停まれる場所マップ）・礼拝（走行統合）は現地インタビュー結果により対象外としたため、UC-001（走行中に停まって礼拝する）を削除した。
