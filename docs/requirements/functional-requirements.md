# Functional Requirements

## 1. Overview

本書は事業要件（BR）を実現する機能要件を定義する。各機能要件に一意の `FR ID` を付与し、`Related BR ID` で BR を参照する。`Phase` は機能概要書のフェーズ定義（MVP / P2）に準拠する。出典は `Safar_機能概要書.docx` v2.0 および `Safar_要件定義書.md`。

`領域` は 食 / 荷物 / 言葉 / 基盤 / B2B。

---

## 3. スコープ外（保留）

機能概要書 第6章に従い、以下は本リリース対象外。中核価値の検証後に追加可否を判断する。

- ビザ・在留管理（在留期限リマインダー、更新手続き）
- 生活立ち上げ（銀行口座・SIM・住居・外免切替・役所手続き）
- 送金・お金（国際送金比較、給与明細解説）
- 健康・緊急（医療機関検索、健康管理）※事故対応フレーズは FR-012 に内包
- 同郷コミュニティ（ドライバー間 SNS・地域グループ）
- 採用前・送り出しガイド、登録支援機関の生活支援義務対応

道（停まれる場所マップ）・礼拝（走行統合）は現地インタビュー結果により対象外とした（当初は中核機能として想定していたが、実際のユーザーニーズと合致しなかった）。

## 4. Notes

- `FR ID` は `FR-001` 形式で採番する（`領域` 列で食/荷物/言葉/基盤/B2B を区別）。
- 画面・データ・外部連携の詳細は `docs/specifications/` で管理する。
- 実装着手前に決める事項は各 OpenSpec change の Open questions / Issue に記録する（商品DB・OCR/翻訳/音声プロバイダ・伝票フォーマット対応・荷主連携フロー 等）。
