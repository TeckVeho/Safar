# External Integration Spec

## 1. Overview

本書は Safar が連携する **外部サービス** の仕様（認証・データ送信範囲・エラー方針）を管理する。全プロバイダ **未選定（TBD）**。選定時に本書へ追記する。

要配慮情報（位置・信仰・伝票画像等）を外部送信するため、**送信範囲・保持ポリシー・リージョン** を各連携で明文化する（NFR-003）。

---

## 2. 連携一覧

| 連携 | 用途 | Related FR | 候補/状態 |
|---|---|---|---|
| 地図 / ジオコーディング | 近隣ハラル店表示 | FR-010, FR-011 | TBD |
| OCR | JAN/成分ラベル・伝票の文字認識 | FR-006, FR-013, FR-028 | TBD（端末内 or クラウド） |
| 機械翻訳 | 伝票・自由文の翻訳 | FR-013 | TBD |
| 音声 STT/TTS | ハンズフリー入力・読み上げ | FR-014, FR-020 | TBD（端末内優先） |

---

## 3. 連携ごとの記載項目（テンプレート）

各連携が確定したら以下を記す。

- 認証方式（APIキー / OAuth 等）
- リクエスト/レスポンス概要
- **送信するデータと範囲**（画像・音声・位置の最小化）
- **保持・ログポリシー**（プロバイダ側の学習利用可否を含む）
- リージョン / データ所在
- エラー・レート制限・フォールバック（オフライン時挙動）
- コスト前提

---

## 4. 共通方針

- 端末内処理で完結できるもの（音声・一部 OCR）は外部送信を避けることを優先（プライバシー・オフライン）。
- 外部障害時はオフライン中核機能を維持（NFR-007）。エラーはログ記録（NFR-008）。
