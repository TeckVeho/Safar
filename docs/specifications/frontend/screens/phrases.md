# SCR-005 フレーズ集

| 項目 | 値 |
|---|---|
| Screen ID | SCR-005 |
| Related FR | FR-012, FR-014 |
| Related UC | UC-005 |
| Phase | MVP |

---

## 1. Purpose

トラックの現場で実際に使う日本語の定型対訳を、カテゴリ別に提供する。運転中も音声で使える。

---

## 2. カテゴリ

| カテゴリ | 内容 |
|---|---|
| 点呼 | 出発前後の確認・アルコールチェック |
| 伝票 | 伝票内容の確認・受け渡し |
| 荷役 | 倉庫での指示・置き場所 |
| 荷主対応 | 荷主とのやり取り |
| 事故・トラブル | 事故/トラブル時の定型 |

各フレーズは **日本語＋対象言語（露／ウズベク）** の対訳で保持（FR-015）。

---

## 3. Layout

```
┌───────────────────────────────┐
│ カテゴリタブ：点呼/伝票/荷役/荷主/事故 │
├───────────────────────────────┤
│ フレーズリスト                    │
│  「この荷物はどこに置きますか？」  [▶]│
│  «Куда поставить этот груз?»       │
│  ……                              │
└───────────────────────────────┘
```

---

## 4. 振る舞い

- フレーズ選択で対訳表示＋**読み上げ（TTS）**、音声入力にも対応（FR-014 / NFR-002）。
- オフラインで参照可能（定型対訳は同梱/同期、NFR-001）。
- 伝票の自由文翻訳が必要な場合は SCR-006（伝票カメラ翻訳）へ。

---
