# SCR-001 ホーム

| 項目 | 値 |
|---|---|
| Screen ID | SCR-001 |
| Related FR | FR-006〜FR-009, FR-026〜FR-029, FR-012, FR-019, FR-021 |
| Related UC | UC-002, UC-008 |
| Phase | MVP |

---

## 1. Purpose

アプリの中心画面。荷物チェック・ハラルスキャン・フレーズ集・近くのハラル店への導線を1画面で提供する。

---

## 2. Layout

```
┌───────────────────────────────┐
│ ステータス（言語表示）           │
├───────────────────────────────┤
│ クイックアクション              │
│   [荷物チェック]  [ハラルスキャン] │
│   [フレーズ集]   [近くのハラル店]  │
├───────────────────────────────┤
│ 最近のスキャン履歴              │
│   ・焼きおにぎり → OK          │
│   ・伝票#123 → 豚含有あり       │
└───────────────────────────────┘
```

---

## 3. Component Placement

| エリア | 要素 | 備考 |
|---|---|---|
| 上部 | 言語・ステータス | |
| 中央 | クイックアクションカード | 主要4機能への導線 |
| 下部 | 最近のスキャン/チェック履歴 | ハラル判定・荷物チェック結果 |

---

## 4. 振る舞い

- 各クイックアクションタップで対応画面に遷移
- 最近の履歴から過去の判定結果を再確認可能
- オフライン時はオフライン表示を出す（NFR-001）

---

## 5. 状態

| 状態 | 表示 |
|---|---|
| オフライン | キャッシュ済み履歴を表示し、オフライン表示を出す |
| 初回起動 | クイックアクションのみ表示（履歴なし） |

---

## 6. データ/連携

| タイミング | API/機能 | 目的 |
|---|---|---|
| 表示 | ローカルキャッシュ | 最近のスキャン/チェック履歴 |
