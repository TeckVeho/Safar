## 1. Purpose

コンビニ・スーパーの棚の前で商品をスキャンし、「食べてOK／避けて／疑わしい」を根拠付きで即時提示する。

---

## 2. Layout（LP の scan-demo を参照）

```
┌───────────────────────────────┐
│ カメラビュー（JAN / 成分ラベル）    │
├───────────────────────────────┤
│ 判定結果カード                    │
│  [icon] 焼きおにぎり（昆布）        │
│         豚・アルコール不使用    OK  │
│  [icon] ポークカレーまん           │
│         豚肉を含みます        避けて │
│  [icon] グミ（果汁）               │
│         ゼラチンの由来が不明  疑わしい │
└───────────────────────────────┘
```

---

## 3. 判定表示仕様

| 区分 | バッジ | 配色（LP） | 意味 |
|---|---|---|---|
| OK | 食べてOK | 緑 | NG 成分が検出されない |
| NG | 避けて | 赤 | 豚由来・アルコール・動物性ゼラチン等を検出 |
| maybe | 疑わしい | サフラン | 由来不明・確証なし（安全側） |

- 各結果に **検出根拠**（該当成分名／表示箇所）を必ず添える（FR-008）。
- maybe 時は「最終判断はご自身で」を明示（FR-009 / NFR-004）。

---

## 4. 振る舞い

1. カメラ起動 → JAN 読取を優先、未登録/読取不可なら成分ラベル OCR にフォールバック（FR-006）。
2. データサービスのハラル判定を呼び出し（`../backend/data-services.md` §ハラル判定）。
3. 3 区分＋根拠を表示。確証なしは maybe（FR-009）。
4. 「食べられるものリスト」（SCR-004）へ遷移可能。

---

## 5. 状態

| 状態 | 表示 |
|---|---|
| 読取失敗 | 再撮影/手入力（商品名）へ誘導 |
| オフライン | 頻出商品キャッシュで判定可否を提示。判定不能時はその旨表示（キャッシュ範囲 TBD: architecture A5） |
| 判定不能 | maybe として根拠（情報不足）を提示 |
