# Architecture

## 1. Purpose and Scope

本書は Safar（ドライバー業務特化版）の全体アーキテクチャを定義する。主要コンポーネント、責務、オフライン方針、外部連携、要配慮情報の取り扱いを扱う。データサービスの詳細仕様・データ定義は `docs/specifications/` に、インフラ構成は [infrastructure.md](./infrastructure.md) に置く。

本書は差し替え対象の成果物であり、技術選定は確定後に更新する。未確定箇所は **TBD** と明記する。

---

## 2. Overview

Safar は **運転中・荷役中・圏外** を前提とした **モバイルアプリ中心 + 軽量バックエンド（データサービス）** 構成を取る。中核体験（食・荷物・言葉）は、端末側のオフラインキャッシュ・端末センサー・音声 I/O で完結することを優先し、サーバーはデータ配信と重い処理（OCR/翻訳の一部、データ更新）を担う。

```txt
端末（モバイルアプリ）
  ├─ GPS / カメラ / マイク・スピーカー
  ├─ オフラインキャッシュ（ハラル店リスト / フレーズ）
  │
  │  HTTPS / JSON（オンライン時）
  ▼
データサービス（Backend）
  ├─ ハラル判定API（JAN→成分DB, NG成分辞書）
  ├─ 荷物チェックAPI（伝票OCR→商品照合→豚含有判定）
  ├─ フレーズ/翻訳API（OCR翻訳, 定型対訳）
  ├─ B2B連携（稼働・定着, 配車・点呼）〔P2〕
  ▼
外部サービス（TBD）
  地図 / OCR / 機械翻訳 / 音声（STT・TTS）プロバイダ
```

---

## 3. Frontend（モバイルアプリ）

主な責務:

- UI 描画・ナビゲーション
- 端末センサー利用：GPS（現在地）、カメラ（スキャン/OCR・伝票/バーコードスキャン）、マイク・スピーカー（音声ファースト）
- **オフラインキャッシュ**：ハラル店リスト・現場フレーズを圏外で参照（NFR）
- 多言語 UI（露・日 / ウズベク P2）と音声操作
- 要配慮情報（位置情報）の明示同意フロー

技術スタック: **TBD**（ネイティブ / クロスプラットフォームのいずれか。オフライン・センサー・音声・カメラOCRの実現性で選定）。

---

## 4. Backend（データサービス）

主な責務:

- 商品・フレーズ等のマスタ配信と差分同期
- ハラル判定（JAN 照合 → 成分解析 → NG 成分辞書照合 → 3区分＋根拠）
- 荷物チェック（伝票OCR → 商品DB照合 → 豚含有判定 → アラート）
- OCR/翻訳のサーバー処理（端末で完結しない部分）
- B2B：稼働・定着の可視化、配車・点呼連携〔P2〕

技術スタック: **TBD**。

---

## 5. オフライン方針

| データ | 取得 | オフライン参照 |
|---|---|---|
| ハラル店リスト | 事前同期 | 可 |
| 現場フレーズ（定型対訳） | 同梱 + 同期 | 可 |
| ハラル判定（JAN/成分） | オンライン優先、頻出商品はキャッシュ | 一部可（TBD） |
| 伝票 OCR 翻訳 | オンライン処理想定 | 不可（オフライン時は撮影保留）TBD |

復帰時に投稿・キャッシュ差分を同期する。

---

## 6. 認証・利用者

- ドライバー個人利用は **匿名/最小登録** を基本とする（要配慮情報の最小収集）。認証方式 TBD。
- B2B（運送会社）管理画面は別途認証が必要〔P2〕。

---

## 7. 要配慮情報の取り扱い

- 位置情報は **要配慮個人情報** として扱う。
- 最小収集・明示同意・保存時暗号化・同意撤回手段を備える（[nonfunctional-requirements.md](../requirements/nonfunctional-requirements.md) NFR、[external-api-spec.md](../specifications/backend/external-api-spec.md) 参照）。
- 外部プロバイダへ送る画像/音声/位置の範囲と保持ポリシーを明文化する（TBD）。

---

## 8. 外部連携

地図（ハラル店表示用）・OCR・機械翻訳・音声（STT/TTS）の各プロバイダは未選定（**TBD**）。連携仕様・認証・データ送信範囲・エラー方針は [external-api-spec.md](../specifications/backend/external-api-spec.md) で管理する。
